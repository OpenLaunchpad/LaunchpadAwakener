# 0005 - 在注入版 App 里整理 Launchpad 的布局

- **状态**: Implemented
- **创建日期**: 2026-11-09
- **最后更新**: 2026-11-09
- **实现分支 / PR**: 直接提交在 `main` 上
- **配套文档**: [实现说明](../Internal/LaunchpadOrganizer.md)

## 摘要

在 Launchpad 里一个个拖图标来整理太费劲：一次只能拖一个，跨页要等翻页，几十个 App 要归类就得拖几十次。本提案在注入版 App 里加一个「整理 Launchpad」窗口：左边是页与文件夹的目录，右边是选中项里的 App 列表，可以多选，再一次性移进文件夹、新建文件夹、移到别的页或移出文件夹；还能拖动排序、给文件夹改名或解散，以及按名称排序、按 App Store 分类一键归进文件夹。改动经 payload 交给 Dock 的布局库，即时生效，Launchpad 下次打开就是新的布局。

## 方案

### 窗口

- 从控制面板「Launchpad」一节的「Organize…」按钮和菜单栏菜单打开，是一扇单独的窗口。
- 左侧栏是目录：每一页一行，页下面列出这一页上的文件夹，带 App 个数。选「第 N 页」时，右边列出这一页上的 App 与文件夹；选某个文件夹时，列出文件夹里的 App（跨它的各页）。
- 右边是可多选的列表：图标、名称，搜索框按名称过滤，搜索时跨所有页与文件夹。
- 操作放在工具栏和右键菜单里，作用于选中的各项：
  - 移到…：子菜单列出每一页、每个文件夹，以及「新的一页」。
  - 新建文件夹：把选中的 App 放进一个新文件夹，接着给它命名；新文件夹放在选中项中第一个原来的位置。
  - 移出文件夹：放到文件夹所在那一页的末尾。
  - 改名、解散（文件夹）：解散时里面的 App 原样排在文件夹原来的位置。
  - 按名称排序：把当前选中的这一页或这个文件夹里的项按名称排好。
  - 一键归类：只动不在文件夹里的 App，按它们的 App Store 分类（`LSApplicationCategoryType`）归进以分类名命名的文件夹；已有同名文件夹就放进去，只有一个 App 的分类不建文件夹。动手前先列出要建哪些文件夹、各放哪些 App，确认后才执行。
- 拖动：列表里上下拖动调整顺序；拖到左侧栏的某页或某个文件夹上，等于「移到…」。
- 空页不必手动删：布局库每次编辑后都会删掉空页与只剩一个 App 的文件夹，与在 Launchpad 里拖动一样。

### 数据怎么走

- **Dock 里的布局库仍是唯一写数据库的地方**，App 绝不直接打开数据库。窗口要的数据和所有改动都经 payload 通道传：
  - 「取布局」请求：payload 回一份布局快照，只有每项的编号、名称、bundle ID、App 所在路径（App 据此取图标，同 ID 的几个 Xcode 各取各的），以及文件夹的名称和分页，不带图标数据和书签。快照带一个版本号，布局每变一次加一。
  - 「改布局」请求：带着改动所依据的版本号和一批编辑。payload 在一个事务里依次应用，回新的快照。版本号对不上（这期间在 Launchpad 里拖过，或 App 装卸触发了对账）就整批拒绝并回最新快照，窗口刷新后让用户再做一次，免得按过期的编号移错东西。
  - Launchpad 正开着时拒绝改动，并说明原因。
- 布局库新增几种编辑：一批编辑在一个事务里完成、只发布一次布局；解散文件夹；按给定顺序重排一页或一个文件夹。其余操作由已有的移动、建文件夹、放进文件夹、移出文件夹、改名组合而成。
- 窗口开着时每 3 秒问一次版本号，有变化才取整份快照，与控制面板的刷新同一个节奏。
- 线上的请求与快照类型照现有约定放在 `LaunchpadAwakenerPayloadInterface`；App 只链接 AppCore，AppCore 把它们转成自己的类型再交给窗口。
- 窗口的逻辑（选中项怎么变成一批编辑、一键归类的方案）放在 AppCore，写单元测试；SwiftUI 只负责显示和转发操作。

### 分批落地

1. 布局库：批量编辑、解散、重排、版本号，加单元测试。
2. payload 通道：取布局与改布局两个请求，payload 一侧的处理与拒绝规则。
3. 窗口：目录、列表、多选、搜索，以及移到、新建文件夹、移出、改名、解散。
4. 拖动排序与拖到侧栏。
5. 按名称排序与一键归类。

每批编完跑全部测试；第 3 批起部署到测试 MacBook，界面效果由用户看。

### 没有询问就采用的假设

- 只在注入版里做。独立版有自己的布局库，以后要的话可以复用同一个窗口。
- Dock 没注入或 payload 是旧版时，窗口只说明原因（并给「重启 Dock」按钮），不显示也不改布局：旧 payload 不认识新请求。
- 不做「从 Launchpad 隐藏某个 App」。15 没有这个功能，布局库也没有地方存。
- 没有撤销。每一步都是普通的布局编辑，做错了再移回去。
- 一键归类只读 App 自己声明的分类，没声明的 App 不动。
